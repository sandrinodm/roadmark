## Expected volume

Beta launch week produced 610 tickets from 1,900 new organisations. We expect 1,800 to 2,400 tickets in GA launch week. The top five beta categories were API keys (18%), concurrency limits (14%), egress denied (12%), billing questions (9%) and template requests (8%). Each gets a macro and a docs link before launch.
