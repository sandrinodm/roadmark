## Positioning

**For** teams building AI agents that run code, **Cloche** is a sandbox API that gives every agent run its own microVM. **Unlike** containers on a shared kernel or a do-it-yourself VM pool, Cloche boots in under 200 ms at p50, snapshots in one call and forks a running machine.
