## Template definition

A template is an OCI image plus a warm-up script. Cloche boots it, runs the warm-up, and stores the result as the template's base snapshot, so the warm-up cost is paid once.

```toml title="templates/browser-chromium/template.toml"
name = "browser-chromium"
image = "ghcr.example/cloche-labs/browser-chromium:2027.02"
default_cpu = 2
default_memory = "4GiB"

[warmup]
# Runs once at template build time; the resulting memory is part of the snapshot.
command = "python -c 'from playwright.sync_api import sync_playwright as p; b = p().start().chromium.launch(); b.close()'"
timeout = "5m"

[egress]
default_allow = ["pypi.org", "files.pythonhosted.org"]
```

Custom templates use the same file with `image` pointing at the customer's registry, built with `cloche template build`.
