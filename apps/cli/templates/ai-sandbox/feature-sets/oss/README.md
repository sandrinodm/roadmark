## What is open and what is not

Open under Apache-2.0: the CLI, both SDKs, the template definitions, examples and the GitHub Action. Closed: the control plane, scheduler, host agent and snapshot store. We say this plainly in the README rather than letting people find out.

## Launch-day bar

The repository goes public at 15:30 UTC on launch day, 30 minutes before the announcement, so that links in the post resolve. Before that it must pass the checklist in [Public repository](items/public-repo.mdx).
